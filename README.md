# Anton Grachev

I build backend APIs and full-stack tools that turn live data into something people can use. The projects below cover forecasting, route planning and navigation, and browser extensions. Each repository explains how the project works, how to try it, and what its tests cover.

## Featured projects

| Project | What it does | Stack |
| --- | --- | --- |
| [RecLive](https://github.com/ant0n-grachev/RecLive) | Helps UW–Madison students decide when and where to exercise with current occupancy, XGBoost forecasts, opening hours, and one-time crowd alerts. Built with [Alex Gabrichidze](https://github.com/alexgabrichidze). [Open RecLive](https://reclive.netlify.app/) | React, TypeScript, FastAPI, SQL, XGBoost |
| [BRouter](https://github.com/ant0n-grachev/BRouter) | Plans Madison BCycle trips using pickup bike and return dock availability, then provides in-app walking and cycling directions. [Open BRouter](https://bcycle-router.netlify.app/) | React, TypeScript, GBFS, openrouteservice |
| [Revelio](https://github.com/ant0n-grachev/Revelio) | Helps people inspect potentially hidden webpage text with in-page highlights and local reports. Findings are clues for manual review. [Chrome Web Store](https://chromewebstore.google.com/detail/revelio/hdcjpjjfangdnigmhdnnmhndanhejeem) | JavaScript, Chrome Manifest V3 |
| [QuietView](https://github.com/ant0n-grachev/QuietView) | Explores attention and display privacy by substituting selected browser signals. The project documents its coverage and where websites can still observe state. | JavaScript, Chrome Manifest V3, Playwright |
